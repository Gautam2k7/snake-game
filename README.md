# Snake Game

Classic Snake Game built with HTML, CSS, and JavaScript.

## How to Play

1. Open `index.html` in your browser
2. Use Arrow Keys to move the snake
3. Eat the red food to grow and score points
4. Don't hit the walls or yourself!
5. Press Space to pause/unpause

## Features

- Classic snake gameplay
- Score tracking with high score saved in localStorage
- Retro styling with neon colors
- Pause functionality
- Responsive canvas
